도쿄역 일번가 할인쿠폰

도쿄역 야에스출구와 직결되어 있는도쿄역 일번가 쿠폰입니다.
500엔 할인 및 면세 혜택을 받을 수 있으며, 선착순 소진 시 종료됩니다. ※ 2026년 4월 1일 ~ 2027년 3월 31일까지 사용 가능합니다.

쿠폰 사용 안내

사용방법
  • ✔ 2,200엔(세금포함) 이상 구매 시 500엔 할인됩니다.
  • ✔ 도쿄 캐릭터 스트리트 & 도쿄 기프트 팔레트 내의 매장에서 사용 가능합니다.
  • ✔ 계산 시, 제시해 주세요. (이용 시 인터넷 환경 필요)
유의사항
  • ✔ 결제 시, 쿠폰을 반드시 제시해 주세요.
  • ✔ 결제 완료 후 쿠폰을 제시하시면 쿠폰을 사용하실 수 없습니다.
  • ✔ 다른 쿠폰, 전자 결제와는 중복 사용할 수 없습니다.
  • ✔ 해당 쿠폰은 하루에 1회 사용할 수 있습니다.
  • ✔ 1대의 스마트폰에서의 쿠폰 사용은 1회만 가능합니다.
  • ✔ 외국인 여행객만 사용할 수 있습니다. (여권 제시를 요청드릴 수 있습니다)
  • ✔ 선착순 400명까지 사용 가능하며, 준비된 수량 소진 시 종료됩니다.
